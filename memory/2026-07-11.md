## Content Wizard SPA (index.html) — Found!
- There are **TWO separate SPAs**: `dashboard.html` (Clone Studio) and `index.html` (Content Wizard)
- `index.html` uses API base `/api/tiktok` (NOT `/api/tiktok/ugc` like dashboard.html)
- Content Wizard is a 4-step wizard in `/frontend/public/index.html`

### 4 Steps:
1. **Product** — URL (Shopee/Lazada), Image Upload (Product + Model), Aspect Ratio (9:16/16:9/1:1/4:5), Product Title, Product Details, Recipe Preset (dynamic from API), UGC Style (Holding/Usage/Review/Talking Head), Duration (8s/16s)
2. **Script** — Hook, Value Proposition, CTA (editable after auto-generation)
3. **สรุปก่อนสร้างรูป** — Summary page showing thumbnail, hook, value, cta, duration, scene desc, voice, AI prompt, mood, hashtags. Button: ✨ สร้างรูป
4. **Generate Video** — Pipeline selector, duration, advanced (negative prompt), 🚀 Generate Video button

### API Flow (Content Wizard):
1. `POST /api/tiktok/scripts/generate` — generate script from product info (hook, value, cta)
2. `POST /api/tiktok/images/build-prompt` — build AI image prompt via Prompt Builder (port 8117)
3. `POST /api/tiktok/images/generate` — generate image via modules-image (Prodia)
4. `POST /api/tiktok/video/generate` — main generation endpoint (NOT `/pipeline/run`!)
   - Sends: product_title, product_url, product_image, hook, value, cta, ugc_style, aspect_ratio, duration, negative_prompt, recipe
   - This calls modules-video internally
5. Poll `GET /api/tiktok/video/status/{job_id}` every 5s until completed/failed

### Key differences from Clone Studio (dashboard.html):
| Feature | Content Wizard (index.html) | Clone Studio (dashboard.html) |
|---------|---------------------------|------------------------------|
| API base | `/api/tiktok` | `/api/tiktok/ugc` |
| Script gen | `POST /scripts/generate` | `POST /scout/templates/generate` |
| Image gen | Yes (2-step: build-prompt → generate) | No (uses pipeline only) |
| Pipeline entry | `POST /video/generate` | `POST /pipeline/run` |
| Polling | Polls `/video/status/{id}` | One-shot (no polling in FE) |
| UGC Styles | 4: holding, usage, review, talking | Templates only |
| Image Upload | Yes (Product + Model via FileReader) | No |

### Lessons
- There are TWO frontend SPAs serving different workflows. The Content Wizard (index.html) is the more complete one with image upload, recipe presets, and full 4-step flow.
- The API prefix mismatch (`/api/tiktok` vs `/api/tiktok/ugc`) is critical — they route to the same TUS backend but different endpoints.
