|---|---|---|

#### Root cause of 5-min timeout
- Old code sent `negative_prompt`, `width`, `height` in img2img config
- Prodia validation rejects those fields → returns `400` with job stuck in "created"
- Our code treated `400` as "queued" and polled every 2s for 5 minutes (150×2s)
- Job never completes because it was never accepted

#### Fixes applied:
1. **`modules/image/main.py`**: `prodia_generate_img2img()` — removed `negative_prompt`, `width`, `height` from config; handle 200 directly; error on 400 immediately
2. **`pipeline_affiliate.py`**: `generate_video()` — receive video directly from response body; removed polling code
3. **Both `_poll_job()` and `_poll_prodia_job()`**: 404 detection, `state.current` check, validation error detection
