### The Great Exec Block (wasted ~5h)
- Root cause: host-level runtime policy (`security=deny`) plus broken `openclaw.json` config
- Problems found and fixed:
  - `allowFrom.webchat: "*"` → `["*"]` (string→array)
  - `exec.mode: "allow"` → `"ask"` (invalid schema value)
  - `mode: "auto"` + `ask: "always"` conflict → removed `ask`, kept `mode: "ask"`
  - `safeBins` missing shell tools → added `sh`, `bash`, `python3`, `node`, `docker`
  - `agents.defaults.tools` not supported → removed, kept at root level

- Gateway tool also broken: `gateway closed (1008): unauthorized: gateway token mismatch`

### Critical lessons
- The approval flow for tools (proposal → user approval → callback) MUST happen in **one single turn** — proposals expire across turns
- User gets frustrated by back-and-forth and approach changes
- Schema Engine port: 8100 (internal only, not exposed publicly)
- Video service port: 8111
- Pipeline uses Schema Engine GET /api/v1/data/video_recipe?search=<name> exclusively
