### 2. แก้ไขโค้ดเพื่อใช้งาน OpenCode API
เปิดไฟล์ `ugc_schema_client.py` และเพิ่มโค้ดดังนี้:
```python
import os
from opencode import OpenCodeClient

# ตั้งค่า API Key จาก .env
DEEPSEEK_API_KEY = os.getenv('DEEPSEEK_API_KEY')

# สร้างฟังก์ชันเพื่อเรียกใช้งาน OpenCode API
def call_opencode_api(prompt):
    client = OpenCodeClient(api_key=DEEPSEEK_API_KEY)
    response = client.chat.completions.create(
        model="opencode-go/deepseek-v4-flash",
        messages=[{"role": "user", "content": prompt}],
        max_tokens=1024
    )
    return response.choices[0].message.content
```

### 3. ใช้งานฟังก์ชันในส่วนที่เกี่ยวข้อง
ในส่วนที่ต้องการใช้งาน DeepSeek V4 Flash เช่น `analyze_product`:
```python
def analyze_product(prompt):
    return call_opencode_api(prompt)
```

pm2 restart prompt-builder
