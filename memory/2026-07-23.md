# Check if features or product_appearance mentions motion/sensor

is_sensor = any(w in pa_clean_lower + feature_str_lower for w in ["motion", "sensor", "detect", "movement", "pir"])

else:

**Fix 3 — Strip leading article from pa_clean:**
