# 2026-07-15 — Frontend Connect TUS to AitoEarn (12:40–12:56 UTC)

## Problem Discovered
User reported TUS frontend at `https://openhands.m2igen.com/tiktok/` showed no connected platforms — all "Loading..." forever.

## Root Cause — Frontend Completely Disconnected
`PFM_API = window.location.origin + '/ugc'` — this prefix **doesn't exist**.
- Calls like `/ugc/accounts` hit Express server (port 8120) → SPA fallback → serves `index.html` as text
- Browser tries to JSON-parse HTML → fails silently → "Loading..." forever

1. **`PFM_API`** → `window.location.origin + '/api/tiktok'` (nginx proxies `/api/tiktok/*` → 8105)
2. **`pfmFetchAccounts()`** — added `aeFetchStatus()` to fetch AitoEarn platforms + merge with local accounts
3. **`pfmPostNow()`** — rewired to use `POST /api/publisher/enqueue` → `POST /api/publisher/{id}/post-now`
4. **`pfmSchedule()`** — rewired to use enqueue with `schedule_at`
5. **`pfmFetchHistory()`** — rewired to use `GET /publisher/queue`
6. **`loadAccounts()`** — added AitoEarn accounts alongside local session accounts
7. **`loadScheduledPosts()`** — now calls `/publisher/queue` instead of `/posts/scheduled`
8. **Auto `post-now`** — `pfmPostNow()` auto-publishes immediately after enqueue and upload

## nginx Routes Added
```
location ^~ /api/aitoearn/ { proxy_pass http://127.0.0.1:8105; }
location ^~ /api/publisher/ { proxy_pass http://127.0.0.1:8105; }
```
