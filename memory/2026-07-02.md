## Google Colab Free Tier Discussion (10:29 UTC)
**Question**: Should TUS use Google Colab Free tier for the entire Video Pipeline during Beta?

**Verdict: Hybrid approach recommended ❌ Don't move entire pipeline to Colab**

### Why Colab Free is good for:
- Wav2Lip Lip Sync (GPU-dependent, server has no GPU)
- Prototyping/testing new models
- Occasional manual runs (1-3 clips/day in Beta)

### Why NOT to move entire pipeline:
- **Idle Timeout**: 90 min idle → runtime killed
- **Forced Disconnect**: Every 12 hours max
- **No REST API**: Can't call Colab from backend automatically
- **Slow bandwidth**: Uploading/downloading video files between Colab ↔ Server is slow
- **Unstable IP**: PostForMe/TikTok auth may get blocked

### Recommended Architecture (Hybrid)
| Component | Where to Run | Why |
|---|---|---|
| Product Scraper | Server | CPU task, no GPU needed |
| TTS Generation | Server | CPU task |
| Video Gen (Wan I2V) | **Fal.ai API** (continue as-is) | Automatic, stable API |
| Wav2Lip Lip Sync | **Colab Free/Pro** (occasional) | GPU needed, infrequent |
| Auto Post (PostForMe) | Server | API-based |
| Compose (FFmpeg) | Server | CPU task |

### Cost Comparison
| Option | Monthly Cost | Best For |
|---|---|---|
| Fal.ai API only | ~$20-50 | Automatic pipeline |
| Colab Free | **Free** | Occasional Wav2Lip |
| Colab Pro | **$10/mo** | Active Wav2Lip + longer runtime |
| Colab Pro+ | **$50/mo** | Heavy GPU workloads |
| **Hybrid (Fal.ai + Colab)** | **~$10-30/mo** | ✅ **Best for Beta** |

### Next Step (Proposed)
User may want: Python script to connect Server ↔ Colab via ngrok + FastAPI Webhook for Wav2Lip automation.
