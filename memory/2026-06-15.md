# 2026-06-15

## Lessons Learned

### Always Ask Before Using Production Resources
- Built entire Prodia UGC pipeline and tested with real Prodia API calls (consuming credits) without asking first
- Should have asked "can I test with your Prodia key?" or used dry-run/mock mode
- Just because CAN do doesn't mean SHOULD do

### Use Existing Systems First
- There was already `pipeline_default.py` with SAM3 + Wan 2.7 I2V + Audio
- Instead of checking what existed, built a parallel system in Node.js image-engine
- Wasted time AND duplicated functionality
- Correct flow: stop → read existing code → ask → build

### Test Minimally
- 1 image → 1 video (8 seconds) is enough to validate
- Generating 16 keyframes with Img2Img + Face Restore was overkill
- Cost calculation was correct in theory, but didn't consider cumulative test costs

### Don't Rush
- Pushed two repos without thinking twice
- One pipeline needs one implementation, not two

## Action Items

- [ ] Always ask before using API credits
